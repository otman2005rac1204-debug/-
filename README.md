# مولد المشاريع بالذكاء الاصطناعي (تطبيق سطح المكتب)

هذا هو الإصدار المكتبي من مولد المشاريع بالذكاء الاصطناعي، مبني باستخدام React و Electron. يتيح لك هذا التطبيق إنشاء مشاريع برمجية كاملة بناءً على وصف نصي، مع القدرة على تشغيله كتطبيق أصلي على نظام ويندوز.

## الميزات

- **إنشاء المشاريع:** قم بوصف فكرة مشروعك واحصل على بنية ملفات كاملة مع الكود.
- **تحسين الكود:** اطلب تعديلات وتحسينات على الكود الذي تم إنشاؤه.
- **مساعد صوتي:** تحدث مع مساعد الذكاء الاصطناعي للحصول على المساعدة.
- **إدارة مفاتيح API:** قم بتخزين وإدارة مفاتيح Gemini API الخاصة بك بشكل آمن.
- **دعم الوضع الداكن:** واجهة مريحة للعين مع إمكانية التبديل بين الوضع الفاتح والداكن.
- **تصدير كملف `.exe`:** قم ببناء التطبيق كملف تنفيذي لنظام ويندوز.

## كيفية البناء والتشغيل

لتحويل هذا المشروع إلى ملف تنفيذي (`.exe`)، يرجى اتباع الخطوات التالية.

### المتطلبات الأساسية

- **Node.js:** تأكد من أن لديك Node.js (الإصدار 18 أو أحدث) مثبتًا على جهازك. يمكنك تنزيله من [nodejs.org](https://nodejs.org/).

### 1. تثبيت الاعتماديات

افتح واجهة الأوامر (Command Prompt, PowerShell, or Terminal) في المجلد الرئيسي للمشروع وقم بتشغيل الأمر التالي لتثبيت جميع الحزم المطلوبة:

```bash
npm install
```

### 2. تشغيل التطبيق في وضع التطوير (اختياري)

إذا كنت ترغب في تشغيل التطبيق محليًا لأغراض التطوير، استخدم الأمر التالي. سيؤدي هذا إلى بدء خادم تطوير وإطلاق التطبيق في نافذة جديدة.

```bash
npm run dev
```

### 3. بناء الملف التنفيذي (`.exe`)

لإنشاء الملف التنفيذي الخاص بنظام ويندوز، قم بتشغيل الأمر التالي:

```bash
npm run package
```

ستقوم هذه العملية ببناء تطبيق React أولاً، ثم تقوم بتغليفه باستخدام Electron. بعد اكتمال العملية بنجاح، ستجد مجلدًا جديدًا باسم `release` في الدليل الرئيسي للمشروع. داخل هذا المجلد، ستجد ملف الإعداد (مثال: `AI Project Generator Setup 1.0.0.exe`) والملف التنفيذي القابل للتشغيل.
